# صوت دزاير: موقع تحويل النص إلى صوت جزائري (نموذج KasbahTTS)

الموقع يشغّل نموذج KasbahTTS-V0 (مبني على Habibi-TTS وبنية F5-TTS) على خادمك أنت، بدون أي خدمة صوت خارجية.

## ما الذي ينقصك قبل التشغيل
1. **كرت شاشة NVIDIA (GPU)**. النموذج يعمل على المعالج لكن ببطء شديد، ولا يصلح لموقع عام.
2. **صوت مرجعي واحد على الأقل**. النموذج يقلّد الصوت من مقطع قصير، فلا توجد "أصوات جاهزة" بداخله.
   - سجّل صوتك أنت، أو صوت شخص وافق كتابيًا على استخدام صوته تجاريًا.
   - المقطع: بضع ثوانٍ (حوالي 5 إلى 10) بدون ضجيج أو موسيقى، بصيغة wav.
   - ضعه في مجلد `voices/` (مثل `voice1.wav`) واكتب نصه بالضبط وبالحروف العربية في `voices/voices.json`.
   - يمكنك إضافة عدة أصوات (رجالي، نسائي...) بإضافة عناصر أخرى في الملف نفسه.

## التشغيل المحلي (Linux مع GPU)
```
python -m venv venv && source venv/bin/activate
pip install torch torchaudio        # نسخة تناسب CUDA عندك
pip install -r requirements.txt
export ADMIN_TOKEN="كلمة-سر-طويلة"
uvicorn app:app --host 0.0.0.0 --port 8000
```
أول تشغيل يحمّل النموذج من Hugging Face (المستودع MenaVoice/KasbahTTS-V0) والمحوّل الصوتي، ثم يعمل بدون إنترنت.
افتح http://localhost:8000.

**لتجربة الواجهة فقط بدون GPU:** `SKIP_MODEL=1 uvicorn app:app --port 8000` (التوليد يكون معطّلًا).

## التشغيل بـ Docker
```
docker build -t sawt-dzair .
docker run --gpus all -p 8000:8000 -v sawt-data:/data -e ADMIN_TOKEN=كلمة-سر sawt-dzair
```
القرص `/data` يحفظ الأكواد والنموذج المحمّل، فلا تحذفه.

## النشر على الإنترنت
شغّل الموقع على خادم فيه GPU: إيجار خادم GPU شهري (RunPod وVast.ai وأمثالهما) أو منصة GPU تحاسب بالثانية (مثل Modal).
- ضع أمام الخادم Nginx أو Caddy مع شهادة HTTPS، واربط نطاقك.
- مهم: الخادم يخدم طلبًا واحدًا في كل مرة. عند الازدحام يرفض الطلبات الزائدة (`MAX_QUEUE`). إذا كبر الموقع شغّل أكثر من نسخة.
- **التكلفة**: إيجار GPU ثابت سواء استُعمل الموقع أم لا. في بداية المشروع المنصة التي تحاسب بالثانية أرخص غالبًا، وعند كثرة المستخدمين الإيجار الشهري أرخص. احسب تكلفتك قبل تسعير الباقات في `index.html`.

## كيف تربح
1. الزبون يدفع (بريدي موب، CCP، فليكسي، USDT...) فتولّد له كودًا:
```
curl -X POST https://موقعك/api/admin/code \
  -H "x-admin-token: ADMIN_TOKEN" -H "Content-Type: application/json" \
  -d '{"chars":20000}'
```
2. ترسل الكود له عبر واتساب أو تيليغرام، فيدخله في الموقع.
3. الأسعار في `index.html` (500 / 1500 / 4000 دج) مجرد اقتراح، عدّلها.
4. استهدف صنّاع المحتوى على تيك توك ويوتيوب، وأصحاب المتاجر الإلكترونية، ومقدّمي الإعلانات الصوتية.

## الترخيص
- صفحة النموذج KasbahTTS-V0 تذكر ترخيص MIT للأوزان، والنموذج الجزائري الأصلي في Habibi-TTS بترخيص Apache 2.0. هذا يسمح عادةً بالاستعمال التجاري.
- مع ذلك اقرأ ملف LICENSE في مستودع النموذج على Hugging Face قبل الإطلاق، ولا تستعمل نماذج Habibi الأخرى (Unified وSAU وUAE) لأنها بترخيص غير تجاري.
- راجع كذلك تراخيص باقي المكتبات (F5-TTS وVocos).

## حدود النموذج (من صفحته الرسمية)
- يفهم **الدارجة الجزائرية بالحروف العربية فقط**. الحروف اللاتينية والكلمات الفرنسية المكتوبة بها تعطي نتائج غير متوقعة، والموقع يرفضها.
- لا يقرأ الأرقام: تُكتب بالحروف. الموقع يرفض النص الذي فيه أرقام.
- لا يدعم التشكيل: الموقع يحذفه تلقائيًا.
- قد يكرر كلمات أحيانًا. جرّب `NFE_STEP=64` أو قسّم النص إلى جمل أقصر. الخادم يقسّم النص الطويل تلقائيًا إلى جمل.

## حماية من إساءة الاستخدام
- الموقع **لا يسمح للزائر برفع صوت مرجعي**، وهذا مقصود: النموذج يقلّد الأصوات، ولو سمحت برفع الأصوات فستسهّل انتحال شخصيات الناس.
- أضف صفحة شروط استخدام تمنع الانتحال والتضليل والاحتيال، واحتفظ بسجل للأكواد.
- الحصة المجانية محدودة بحسب IP في الذاكرة (تُصفَّر عند إعادة التشغيل). للحماية الأقوى أضف Cloudflare Turnstile أو تسجيل دخول.
